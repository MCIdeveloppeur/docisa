# Documentation ISA33

Ce dossier contient les différents manuels et documents de référence associés à ISA33.

## Contenu

- `index.html` : page d’accueil avec accès rapide à tous les manuels.
- `1MANUEL_MENU_FICHIER_PARAMETRES_ISA33.html` : paramètres du système.
- `2MANUEL_TABLES_DE_REFERENCES_ISA33.html` : tables de références.
- `3MANUEL_MENU_PRODUCTION_ISA33.html` : menu production.
- `4MANUEL_MENU_MEDICAL_ISA33.html` : menu médical.
- `5MANUEL_MENU_PRESTATIONS_ISA33.html` : menu prestations.
- `6MANUEL_MENU_COMPTABILITE_ISA33.html` : menu comptabilité.
- `7MANUEL_MENU_KIT_STATISTIQUE_ISA33.html` : kit statistique.

## Utilisation

1. Ouvrez le fichier `index.html` dans un navigateur.
2. Cliquez sur le manuel souhaité pour y accéder directement.
3. Les fichiers HTML sont conçus pour être utilisés localement ou publiés sur un serveur web.

## Objectif

Ce dépôt sert de point d’entrée centralisé pour la consultation rapide des manuels et documents fonctionnels de ISA33.
